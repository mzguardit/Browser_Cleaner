## Overview

**Browser Cleaner** is a Windows privacy and system hygiene utility originally launched in **2009** by **Vincenzo Chieppa (SoftEdition / MZGuard)**. Built to go beyond standard browser clear-history menus, it locates and permanently removes residual browsing artifacts, cache files, tracking cookies, and system leftovers across major web browsers and Windows applications.

## Key Features

* **Multi-Browser Cleanup:** Supports Chrome, Edge, Firefox, Brave, Opera, and legacy browsers.
* **Deep Artifact Removal:** Eliminates browsing history, disk cache, cookies, saved form/autofill data, and session remnants.
* **Adware & Toolbar Cleanup:** Helps clear unwanted browser extensions, toolbars, and residual tracking entries.
* **Registry & Application Hygiene:** Cleans orphaned Windows registry traces and temporary application caches.
* **Secure Deletion:** Supports DoD 5220.22-M overwriting patterns to prevent forensic recovery of erased traces.
